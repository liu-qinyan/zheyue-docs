## 作品是什么

一个**被玩家偶然发现的互联网遗迹**。

玩家打开一个 2007 年建站、2013 年后停更的个人主页，以为是普通旧博客；
越翻越发现它有三个时期、两套手感、两种签名——最后意识到：
**这个网站是一个人替另一个人继续维护的。**

- 单人游玩，浏览器打开，**单个 HTML 文件**
- 全部资源内嵌：图片用 canvas 运行时合成，声音用 WebAudio 运行时合成
- 离线双击可运行，**零网络请求**，不读 cookie / 位置 / 摄像头 / 麦克风
- 存档只用 localStorage，可一键清空
